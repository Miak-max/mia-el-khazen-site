One exception, asked for by Mia on 10 Oct 2026: on phones, projects 9–15 (the Interlude series, selector `.collage[class*="collage--p-interlude-"]>.ph` in the phone media query) force every piece, clips included, into the same 84 %-wide 3:2 frame (`aspect-ratio:3/2!important`, `object-fit:cover` crops it) so they alternate left / right exactly like projects 1–8, which the client liked; before that, their full-width 16:9 clips and mixed photo shapes broke the rhythm. That tool *composes* each project collage as an editorial stack (8 Oct 2026, the user: "same gutter in every section, well spaced, medias not side by side, more aligned"): one piece per row, never two side by side; the lead flush left and wide (70 / 54 / 40 % by shape), the rest zigzag flush right / flush left at one of three fixed widths (landscape 58, square 46, portrait 36 %), and the one `GUT` (2.2 %, tightened the same day: "too separated") under every piece. It regenerates the CSS between the `LAYOUTS` markers; phones use the same stack in CSS (84 % wide, even pieces right-aligned, clips full width). `tools/layouts.json` records the result; set `"manual": true` on a key and edit its slots to place by hand. Run it after every `build_images.py` change. The user rejected a tidy justified-rows grid (9 Sep 2026) and the staggered masonry columns (8 Oct 2026): do not go back to either.

Hero captions were removed on 10 Sep 2026 at the user's request — do not add titles to the hero. Keep all of it inside Anton + Bebas + blue + paper. Since 10 Oct 2026 the hero pile is **draggable** (Mia: visitors "are in control of the placements of the pictures"): pointer-event code at the end of the page script moves a piece by writing `left`/`top` in % of the pile (never `transform`, which the reveal owns), brings whatever is touched to the front (`z-index` counter from 10), clamps a piece to half off the sides and inside the pile top to bottom, and swallows the click that follows a drag. Mouse drags at once; touch needs a 280 ms hold first so a swipe still scrolls (`touch-action:pan-y pinch-zoom`, a non-passive `touchmove` preventDefault only while a piece is lifted, `-webkit-touch-callout:none`). `.ph--lift` is the grabbed state (grabbing cursor, 4 % scale). Nothing is persisted: a reload restores the composed layout. `shots/drag-test.html?w=1976` and `?w=390&touch=1` drive synthetic drags and print the result in the corner.
- The reveal means `.ph` starts at opacity 0 when JS runs; `shots/frame.html` adds `.in` to every slot before capturing.

## Reference Images
- If a reference image is provided: match layout, spacing, typography, and color exactly. Swap in placeholder content. Do not improve or add to the design.

- Screenshot your output, compare against reference, fix mismatches, re-screenshot. Do at least 2 comparison rounds. Stop only when no visible differences remain or user says so.

## Local Server
- **Always serve on localhost** — never open a `file:///` URL.
- Start the dev server: `python3 serve.py` (serves the project root at `http://localhost:3000`). Port 3000 is often held by another site's `serve.py` — check with `lsof -nP -iTCP:3000 -sTCP:LISTEN` and, if taken, run `python3 serve.py 3010` instead. Never kill the other server.
- `serve.py` lives in the project root. Start it in the background before previewing.
- If the server is already running, do not start a second instance.

## Screenshot Workflow
- Headless Chrome is available: `./screenshot.sh <url> <out.png> [width] [height]` (use a tall height, e.g. 6400, for a full-page capture).
- Headless Chrome will not go narrower than 500px and ignores `#anchor` scrolling. Use `shots/frame.html`: `?w=390` for mobile (capture at 600px wide, crop the left 390px), `?w=1976&id=<slug>` to put one project block at the top, and `&h=2000` to cap the frame height (a full-page frame loads all 19 videos and Chrome can get killed for memory; with `id` the cap must still reach past that element, e.g. `id=about&h=3400` on desktop). `shots/one.html?w=390&id=<slug>,<slug>` loads the site, drops every other project and the hero collage, and puts the first listed block at the top: the safe way to capture one or two project blocks on the phone. Both helpers live in the git-ignored `shots/`, so recreate them from these notes if they are missing.
- Save captures under `shots/` (git-ignored). Compare against `brief/reference-render.png`.

## Anti-Generic Guardrails
- **Colors:** Never introduce colours outside the brand tokens.
- **Typography:** Anton and Bebas Neue only. Tight line-height on display sizes (`.9`–`1`), `1.12` on Bebas body copy.
- **Animations:** Only animate `transform` and `opacity`. Never `transition-all`.
- **Interactive states:** Every clickable element needs hover, focus-visible, and active states. No exceptions.
- **Spacing:** vw-based rhythm measured from the brief (`--margin: 5.7vw`). Don't introduce arbitrary pixel values.

## Hard Rules
- Do not add sections, features, or content not in the reference
- Do not "improve" a reference design — match it
- Do not stop after one screenshot pass
- Do not use `transition-all`
